AI + Skincare Recommendation Platform

An AI-powered skincare recommendation platform that helps users build routines based on skin type, concerns, sensitivity, and budget.

⚙️ Features
- Skin concern quiz
- Ingredient analyzer
- Routine builder
- AI skincare recommendations
- Product comparison
- Acne/hyperpigmentation tracking
- Progress dashboard
- Personalized routines

⚙️ Tech Stack
- React / Next.js
- Python AI backend
- SQL/PostgreSQL
- OpenAI API or recommendation engine
- Image upload support

⚙️ Goals
This project was built to strengthen:
- Full-stack development skills
- UI/UX design
- API integration
- Recommendation system logic
